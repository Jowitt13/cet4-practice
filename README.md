# CET-4 在线练习

完整模考、专项练习、错题复习，以及本地保存的成绩、批注、听写和写作修订。

包含 76 份资料、45 套完整模考和 406 个共享专项入口。保留静音档案开场、浅色与暗黑模式、电脑／平板／手机布局。

## 使用

网页从 `site/index.html` 打开。页面和题库数据首先加载，音频与原卷图片按需读取；无需一次下载离线版的全部内嵌文件。

学习数据只保存在当前浏览器，不会上传到仓库。换设备、换浏览器或从本地 HTML 迁移时，请在旧页面导出完整 JSON 备份，再在网站的学习记录中导入。网站没有账号或云端成绩同步。

## 部署

仓库使用 GitHub Pages 和 `.github/workflows/pages.yml` 部署 `site/`。仓库设置中的 Pages 构建来源应为 GitHub Actions。更新 `site/` 后推送 `main` 即部署。

此仓库只包含可运行的网站发布文件，不包含原始 PDF、模型、执行环境、审计日志、私人备份或个人学习记录。音频和页面图片以内容哈希命名，原始可用资源的字节保持。

## 记录与评分

完整模考与专项分别记录；含听力模考按现有练习权重计分，关闭听力按实际部分计分。写作和翻译对照参考自评，网站成绩不是官方考试报道分。辅助字幕不是人工听音结论，听写比对不计入模考分数。
